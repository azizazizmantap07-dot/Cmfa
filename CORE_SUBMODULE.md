# Clash core (mihomo)

Build requires `core/src/foss/golang/clash` (MetaCubeX/mihomo, branch Alpha).

If this directory is empty after clone:

```bash
git submodule update --init --recursive
# or
git clone --depth 1 -b Alpha https://github.com/MetaCubeX/mihomo.git core/src/foss/golang/clash
```

The GitHub workflow clones it automatically when missing.
